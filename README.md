# card_check — 우리가족 카드 사용 현황

가족이 함께 쓰는 카드 사용 내역 관리 웹앱. Google Sheets를 데이터 저장소로 사용하는 Google Apps Script 웹앱입니다.

## 특징

- 카드 선택 / 사용일 / 항목 / 금액을 입력해 지출 내역을 기록
- 카드 추가·삭제 (초기 카드: 롯데카드(헬로티비), 롯데카드(재홍), 우리카드(재홍), 삼성카드(정이), 현금사용)
- 지출 내역 추가·삭제
- 카드별 월 지출 합계 및 전체 월 총지출 합계 자동 계산
- "정산월" 기준: 전월 11일 ~ 당월 10일 (예: 8월 정산 = 8.11 ~ 9.10)
- PC / 태블릿 / 모바일 반응형 UI

## 파일 구성

- `Code.gs` — Apps Script 백엔드 (스프레드시트 읽기/쓰기, 정산월 계산 로직)
- `Index.html` — 프런트엔드 UI (HTML/CSS/JS)

## 배포 방법

1. 새 Google 스프레드시트를 만든다 (이 시트가 데이터 저장소로 쓰임).
2. 시트 메뉴 `확장 프로그램 > Apps Script` 를 연다.
3. `Code.gs` 내용을 그대로 붙여넣는다.
4. 파일 추가(`+` → HTML)로 이름을 정확히 `Index` 로 하는 파일을 만들고 `Index.html` 내용을 붙여넣는다.
5. `배포 > 새 배포` → 유형: 웹 앱, 실행 계정: 나, 액세스 권한: 모든 사용자로 설정 후 배포한다.
6. 발급된 웹 앱 URL을 가족과 공유한다.

첫 실행 시 스프레드시트에 `Cards`, `Expenses` 시트가 자동으로 생성되고 초기 카드 5개가 자동으로 채워집니다.
